# 研究与开源参考

## 一、看过的开源项目

### 1. OpenPrep-AI
- 仓库：https://github.com/nishit546/OpenPrep-AI
- 它做什么：分析 lecture notes 和 past year questions（PYQ），自动排学习计划，用间隔重复做记忆保持。
- 借用的思路：**从真题反推复习优先级**，而不是按教材章节平均分配时间；计划要围绕考试日期倒排。
- 没有直接用的原因：技术栈重、依赖外部数据库/模型，不适合“今天就要用”的本地单机场景。

### 2. nano-NotebookLM
- 仓库：https://github.com/ArthurYangX/nano-NotebookLM
- 它做什么：把课程资料变成笔记、知识图谱、带引用的问答和考前题。
- 借用的思路：**每个结论都要能回到原文位置**；问答必须 grounded，资料没覆盖就明说。
- 本项目的做法：考点卡片保存 `doc_id + locator + quote`，资料箱里能回看原文；问教练时返回检索片段。

### 3. DeepTutor（HKUDS）
- 仓库：https://github.com/HKUDS/DeepTutor
- 它做什么：长期个性化辅导、Question Notebook、可视化讲解。
- 借用的思路：**题目本/错题本不是附属功能，而是学习闭环的一部分**；做错后要回到对应知识点，再测一次。
- 本项目的做法：刷题错题自动进错题本；模考主观题按评分点自评；卡片按掌握度安排下次复习。

### 4. Anki / FSRS
- FSRS：https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler
- 借用的思路：主动回忆 + 间隔复习。考试只剩 3 天时，不使用长期间隔，而用“10 分钟 / 1 天 / 2 天 / 4 天”的压缩节奏。
- 本项目的做法：卡片四档自评（忘了/吃力/想起/很熟），后端更新 due 时间和 mastery；首页显示到期卡数量。

## 二、学习科学依据

1. **Dunlosky et al. (2013)**，*Improving Students' Learning With Effective Learning Techniques*：在十种常见学习技巧中，practice testing（检索练习）和 distributed practice（分散练习）证据最强；重读、划线、总结的收益较低。
   - https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html
2. **Roediger & Karpicke (2006)**，*Test-enhanced learning: Taking memory tests improves long-term retention*：测试本身会增强长期保持，不只是测量。
   - https://pubmed.ncbi.nlm.nih.gov/16507066/
3. **Interleaving / worked examples**：交错练不同题型、先看样例再独立做，有助于迁移到新题。本项目的“混合题组”和“最小例子”就是这两个思路的简化落地。

## 三、本项目的原创取舍

现有工具大多解决“资料很多，怎么整理”的问题；你这个场景的真正约束是：

- 只剩 3 天；
- 考试不是全考；
- 有真题但没有完整答案；
- PPT 和 PDF 里大量公式是图片；
- 用户不是要“学会整门课”，是要“在卷面上拿到尽可能多的分”。

所以 ExamSprint 的核心不是 RAG 聊天，而是：

1. **性价比分层**：S 必拿 / A 补漏 / B 最后学或放弃。
2. **真题结构反推**：先还原卷面，再决定学什么。
3. **模板化计算题**：Bayes、一维、二维、数字特征各有固定步骤。
4. **主动回忆 + 错题闭环 + 限时模拟**：三层反馈，不是只看懂。
5. **本地优先**：没有 API Key 也能用；资料不离开本机，除非你主动配置模型。
