## x01｜二维连续型：联合密度、边缘、条件、独立｜calculation

设 (X,Y) 服从区域 D={(x,y)|0≤y≤1−x²} 上的均匀分布，设 B={(x,y)|y≥x²}。

(2) 求 X 和 Y 的边缘密度函数；
(3) 求 X=−1/2 时 Y 的条件密度函数，以及 Y=1/2 时 X 的条件密度函数；

**解析：** 先由区域面积定常数 3/4；边缘密度分别对另一变量积分；条件密度=联合/边缘；B 是 0≤x²≤y≤1−x²，先求面积再除以 4/3。

## s2q05｜二维连续型：联合密度、边缘、条件、独立｜calculation

设 (X,Y) 的概率密度为 f(x,y)=Axy（0<x<1，0<x<y<1），其他为 0。
(1) 求常数 A；
(2) 求边缘概率密度 f_X(x), f_Y(y)；
(3) 判断 X,Y 是否相互独立，并说明理由；
(4) 求 P{X+Y≤1}。

**答案：** A=8；f_X(x)=4x(1−x²)(0<x<1)，f_Y(y)=4y³(0<y<1)；不独立（f≠f_X f_Y）；P=1/6。

**解析：** 积分区域 0<x<y<1；归一化 A∫0¹∫_x¹ xy dy dx=1 得 A=8；边缘积分；乘积不等于联合；区域 0<x<1/2,x<y<1−x 积分。

**评分点：** A 2 分；边缘 4 分；独立性 2 分；概率 4 分

## s2q06｜二维随机变量函数的分布：和、max、min｜calculation

设 X₁,X₂,…,Xₙ 是独立同分布的随机变量，且 X_i 的概率密度为 f(x)=e^(−x)（x>0），其他为 0。记 X=min{X₁,X₂,…,Xₙ}，试求 X 的概率密度 f_X(x)。

**答案：** f_X(x)=n e^(−nx)（x>0），其他为 0。

**解析：** P(X>x)=P(所有 X_i>x)=e^(−nx)，所以 F_X(x)=1−e^(−nx)，求导得 n e^(−nx)。

**评分点：** 生存函数 6 分；密度 4 分
