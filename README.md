# ExamSprint · 考前冲刺 Agent

## 2026-11-02 任务驱动学习流程

本地完整版首页现在按“系统给一个下一步 → 作答 → 自动重排”组织，不再要求用户先做决策。

- 默认按 15 分钟安排本次任务，预算随记录用时扣减；需要调整时才在高级区域修改。
- 首页只展示一个“现在做这一步”，不要求用户判断水平、选择题目或挑候选任务；每次提交后系统自动重排。
- 主观题按题库已有评分点逐项核对，记录完整、部分或尚未完成。部分完成后优先提示遗漏步骤，不把自评当自动阅卷。
- 使用必要讲解或查资料须标记为辅助；辅助完成后优先换一道未练题。旧记录缺少辅助信息，不直接算独立完成。
- 独立完成、不同题目通过和间隔复测分别展示；连续两次未完成时暂缓该考点，避免反复卡在同一题。
- 考试日期已过时停止推荐新冲刺任务，请在资料箱修改日期；当前概率课程已设为 2026-11-04，只有日期，没有考试具体时刻。

本版规则是可解释的初始调度策略，不是提分预测：默认客观题3分钟、主观题10分钟，可由题目的 `estimated_minutes` 覆盖；复测最短间隔30分钟，有待真实使用校准。记录用时是题目停留时间，可能包含中断，不包含其他页面学习。题库不足时会明确标记旧题复测，不伪装成新题。

验证：`python -m unittest discover -s tests -p "test_*.py"`（29项），`node tests/frontend_test.cjs`。已用真实Edge浏览器和临时课程验证完整流程及390px手机布局。静态PWA桥接已补上同一套任务调度逻辑，APK也已重建；静态版的考试日期可在“资料箱 → 考试设置”中修改并保存在浏览器本地。

## 2026-10-31 可靠性修复

- 切换课程会清除旧练习和模考状态；另一窗口切课或重新生成后，旧窗口的进度提交会被拒绝，刷新后重试。
- 重新生成会先将旧冲刺包和进度保存到 `data/courses/<id>/history/`，新包从零计进度，防止顺序题号错配。旧记录可人工恢复，界面暂不提供恢复按钮。
- 抽题优先最近答错与未练题；错题本即时更新；进度保存失败会提示重试；到期卡片完成后显示完成状态。
- 计划支持每日0.5小时，任务总时长严格遵守预算。时间不足整卷时安排限时抽题，整卷需另外安排时间。
- 无真题时，作业重复40% + PPT文字覆盖40% + 明确先修依赖20% 是排序规则；缺失证据不补分，置信度低，不能视为得分预测。
- 非本机监听必须先设置 `EXAMSPRINT_ACCESS_TOKEN`。当前仍为单进程单用户应用。
- 已修正概率统计练习中一题单选存在两个正确选项、一题依赖上一题条件的问题；原有进度保留。

验证命令：`python -m unittest discover -s tests -p test_regressions.py -v`、`node tests/frontend_test.cjs`、`python tests/smoke_test.py`。冒烟测试检查当前课程。

静态构建使用 `python tools/build_static.py --course probability-midterm` 指定课程；省略时读取当前课程。静态包包含课程文本，请确认分享范围。本次已在修复后重建 `web/`、`web/server/`、Android/APK，并更新 GitHub Pages 与 Release；重启本地服务并刷新网页后使用新版。

给《概率统计》期中做的本地冲刺软件。不是“把 PPT 再讲一遍”，而是从**课件范围 + 19 张作业截图 + 2021/2022/2024 期中真题**反推：哪些题必拿、哪些只背结论、哪些直接放弃。

## 直接打开

双击工作区根目录的：

```text
启动概率统计冲刺.bat
```

或本目录的 `启动 ExamSprint.bat`。浏览器会自动打开 `http://127.0.0.1:8765`。关闭启动窗口或双击 `停止概率统计冲刺.bat` 即停止服务。数据全部保存在本机 `data/`。

> 已经预装好《概率统计》冲刺包，**不配置 API Key 也能用**：考点、速学卡、36 张回忆卡、72 道练习、1 套 100 分仿真卷、3 天计划全部可用。配置 Key 只是为了“问教练”和给新课程重新生成。

启动器会优先使用本机 DeepSeek Harness 自带的 Python 3.12（已装 `python-pptx` / `python-docx`）。如果把整个文件夹换到另一台电脑，先执行 `pip install -r requirements.txt`，或用该电脑的 Python 3.12 启动。

## 先看结论：只学这些

| 层级 | 内容 | 估算分值 | 策略 |
|---|---|---:|---|
| **S 必拿** | Bayes、一维密度/F、一维变量函数、二维连续、二维离散、期望方差协方差 | ~70 | 六个计算模板练到能独立写完整步骤 |
| **A 补漏** | 常见分布/正态、事件概率、条件与独立、分布函数性质 | ~25–30 | 只背公式、结论、陷阱，不做证明 |
| **B 最后学** | 二维函数的 max/min/卷积、古典/几何概型 | ~5–10 | 只学模板；复杂计数题直接跳过 |

依据：2024 期中卷面是 **5 填空×3 + 5 选择×3 + 5 计算×14–15，100 分钟**。2024 的五道计算分别落在：Bayes、一维 F/变量函数、二维正态线性组合、二维离散、二维连续。2021/2022 的结构也高度重复。

**战略放弃**：证明题、复杂古典概型、冷门分布推导、需要大量分类讨论的计数题。它们分值低、耗时高，不适合 3 天从零。

## 课程库：换一门课怎么用

点击左上角课程名 → 课程库 → 新建课程。每门课有独立的资料、分析、卡片和进度；概率统计包会原样保留。

只有 PPT + 作业也能生成：

1. 新建课程，上传 PPT 和作业；
2. 在资料箱把文件类型标成“课件 / 作业”；
3. 配置模型后点“生成冲刺包”；
4. 没有真题时，系统会按 **作业重复 40% + PPT 强调 40% + 先修 20%** 排序，并明确标注“低置信度/推断”，不会假装押中真题。

适合文字型课程；公式图片、扫描页、结构图仍需要 OCR/多模态或手工转文字。

## 零基础模式（默认开启）

这版不是“有基础的人冲刺”，而是从没看过书也能开始的路线：

- 先补 6 个数学工具：概率符号、Σ、定积分、分段函数、二重积分、导数。
- 再学 4 个保分模板：Bayes、一维密度、二维离散、数字特征。
- 第 5 个模板是选择填空急救；二维连续和一维变量函数标记为“80 档才学”。
- 目标明确写成 **60 → 80 → 100**：60 靠模板，80 靠补齐二维/变量函数，100 靠完整知识面 + 零失误；不承诺 100。

### Day 1：数学急救 + Bayes + 一维密度（约 6 小时）
1. 先做 10 题零基础诊断，不会就打开对应工具卡。
2. 数学急救只学规则：Σ 展开、∫xⁿdx、分段代入、F 求导。
3. Bayes 模板照着写 3 遍；一维密度只拿“求 c、求 F、求概率”前两问。

### Day 2：二维离散 + 数字特征 + 选填急救（约 6 小时）
1. 二维离散：补表、边缘、独立、max；全是加法。
2. 数字特征：E、D、Cov、ρ 三板斧。
3. 选择填空：背 8 条结论，不推导。
4. 二维连续先不碰；如果前四个模板还不会，直接放弃。

### Day 3：60→80 模拟（约 6 小时）
1. 100 分钟仿真卷，严格计时。
2. 只抓 M1–M5 的错，不补新知识。
3. 最弱模板二次作答；晚上背“零基础速学”的最后两页。

> 如果你的考试不是 3 天后：在“资料箱 → 考试设置”里改日期和每天小时数，重新生成计划即可。

## 五个核心页面

- **零基础起步**：6 个数学工具 + 4 个保分模板 + 10 题诊断 + 照抄模板。
- **总览**：剩余天数、准备度、今日时间块、性价比分层。
- **考点地图**：12 个考点，含 2 分钟讲解、公式、例题、易错点、原文位置。
- **速学 / 回忆**：先看速学卡，再用 36 张卡做主动回忆；按“忘了/吃力/想起/很熟”安排下次复习。
- **刷题**：72 道精编题，提交后立即判分/自评；错题自动进错题本。
- **模拟考**：100 分仿真卷，严格计时；客观题自动判分，主观题按评分点自评。

右上角“问教练”：配置 API Key 后，可基于你的资料回答问题，并标出原文位置；不配置时返回检索到的原文片段。

## 配置 DeepSeek（可选）

1. 右上角“设置”。
2. Base URL：`https://api.deepseek.com/v1`
3. 模型：`deepseek-chat`
4. 填入 API Key → 保存 → 点“测试”。

Key 只保存在本机 `data/settings.json`，不会写进代码或导出文件。调用模型时只发送课程名、必要资料片段和生成提示。

## 加新资料 / 换一门课

三种方式：

1. 在“资料箱”里直接拖入 PPTX / PDF / DOCX / XLSX / TXT。
2. 放到工作区的 `course_input/`，再点“扫描资料夹”。
3. 放到 `exam_sprint/inbox/课件`、`inbox/作业`、`inbox/真题`，再扫描。

然后把资料角色改成“课件/作业/真题”，点“重新生成”。

注意：
- 扫描版 PDF、图片型公式不会自动 OCR；需要先转成可复制文字的 PDF，或像这次一样人工转录关键题。
- 旧版 `.ppt` / `.doc` 请先另存为 `.pptx` / `.docx`。
- 单文件上限 80 MB。

## 这次是怎么处理你的资料的

- `第一章`、`Ch2`、`第三章`、`Ch4` 四份 PPT：抽取 322 张幻灯片的标题、文本和章节结构。
- 19 张作业截图（去重后）：人工转录为 8 页“题目 + 答案 + 错因”，重点保留分布函数、变量函数、二维联合、条件概率。
- `概率统计小册子（高清）.pdf`：38 页扫描版，已记录页数并作为作业范围核对；本次没有逐页 OCR，实际以截图转录为主。
- 2021、2022、2024 三份期中真题：提取卷面结构、题型、分值、重复考点和 2024 最新模板。
- 期末考试、重复 PDF、答案重复版本没有进入本次期中分析，避免把非期中范围带进来。

## 边界（很重要）

- 这是**仿真练习**，不保证命中原题；老师临考划的范围优先。
- 概率统计的公式很多是图片，PPT/PDF 的文字抽取会漏公式；本包的关键公式是人工校对过的。
- 准备度是“卡片覆盖 + 练习正确率 + 模考”的过程指标，不是考试通过率。
- 不提供作弊、代考或泄题功能。

## 静态版与完整版边界

静态 PWA/APK 只含当前概率课程，不能上传、多课程或调用模型；保存失败会明确提示。完整版才支持课程库、资料解析和模型调用。
